About

Photo & Slide Classifier is an offline assistant for assigning official taxonomy categories to groups of archival images.

How it works

  1. Load the official taxonomy text files.
  2. Describe a group of images.
  3. The application searches Subjects, Keywords, and Aircraft.
  4. Review the suggested categories.
  5. Select the categories that actually apply.
  6. Generate a folder label.

Privacy

Classification is performed locally in the browser. The application does not require an internet connection.
