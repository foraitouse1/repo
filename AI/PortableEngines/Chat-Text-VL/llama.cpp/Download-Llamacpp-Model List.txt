VANILLA UPSTREAM LLAMA.CPP MODEL CATALOG
=========================================

NORMAL UPSTREAM LLAMA.CPP
NOT THE UNSLOTH FORK

This catalog contains recommended GGUF models compatible with the
upstream llama.cpp project.

Models are selected for:
- General chat
- Reasoning
- Coding
- Vision
- Multilingual use
- Agentic workloads
- Small/low-memory systems
- High-end systems

The catalog intentionally includes models from multiple Hugging Face
publishers.

A repository does NOT need to belong to ggml-org to be compatible with
vanilla llama.cpp.

The downloader should use the repository listed in the HF REPO column.

The downloader MUST read the HF REPO column.

For example:

    Qwen/Qwen3-8B-GGUF

    ggml-org/gpt-oss-20b-GGUF

    mistralai/Ministral-3-8B-Reasoning-2512-GGUF

    bartowski/Meta-Llama-3.1-8B-Instruct-GGUF

are all different repository naming schemes.

Vanilla llama.cpp supports Hugging Face repositories directly,
including repositories that are not owned by ggml-org.


============================================================
MULTIMODAL MODEL REQUIREMENT
============================================================

Vision-language models may require:

    Primary GGUF model
    +
    mmproj GGUF

The downloader should therefore identify both when required.

The primary language model must NOT be confused with:

    mmproj
    mmproj-F16
    mmproj-F32
    clip
    vision encoder


============================================================
WHY THIS LIST IS MUCH LARGER
============================================================

The Hugging Face llama.cpp/GGUF ecosystem currently contains a very
large number of compatible models. The current llama.cpp-filtered
Hugging Face catalog alone contains tens of thousands of GGUF models,
and current popular entries include Qwen3.6, Qwen3.5, Gemma 4,
GPT-OSS, GLM, Llama, Mistral, Granite, DeepSeek, coding models,
vision-language models, and many community variants.

Therefore, a useful vanilla llama.cpp model catalog should not be
restricted to a dozen or twenty official ggml-org repositories.

It should contain:

1. Official model GGUFs
2. Trusted community GGUF conversions
3. Major current model families
4. Coding models
5. Reasoning models
6. Vision-language models
7. Small models
8. Medium models
9. Large MoE models
10. Older models that remain useful
